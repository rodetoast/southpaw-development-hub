# Southpaw 도구 런처

사내 직원이 제작 도구를 설치·실행·업데이트하는 통합 런처입니다.

- **구현 범위** 도구 5개 관리, 서명 카탈로그 검증, GUI·Bootstrap 관리형 교체와 복구, Toast → Rod 전환, 설정과 테마
- **운영 버전** 0.2.2
- **개발 상태** 0.2.2 운영. 프로그램 관리와 설정 개선 다음에 헤더 공식 회사 심볼을 적용했습니다.
- **다음 단계** 새 개발 과제가 정해지면 기존 직원의 업데이트 버튼과 시작·복구 계약을 유지합니다.
- **확인일** 2026-11-24
