# Southpaw 도구 런처

사내 직원이 제작 도구를 설치·실행·업데이트하는 통합 런처입니다.

- **구현 범위** 도구 5개 관리, 서명 카탈로그 검증, GUI·Bootstrap 관리형 교체와 복구, Toast → Rod 전환, 설정과 테마
- **운영 버전** 0.2.2
- **개발 상태** 0.2.3 Bootstrap v4 개발 후보에서 운영 v3의 자동 교체와 실패 시 복원, 중복 실행 안내 및 합성 도구의 링크 v1→v2를 격리 Windows 환경에서 확인했습니다. 운영은 GUI 0.2.2입니다.
- **다음 단계** [v4 검증 기록](https://github.com/rodetoast/creative-group-launcher/blob/5776e99024243d63a745242154e6d46c94e87ca0/docs/BOOTSTRAP_V4_0.2.3.ko.md)을 기준으로 운영 서명 후보 준비 여부를 결정합니다. 실제 Toast Bridge 전환, 전경 활성화와 작업 표시줄은 미검증입니다.
- **시각 검토 자료** 공식 회사 심볼은 헤더에 적용하고 기존 제품 아이콘은 제목 표시줄에 유지했습니다.
