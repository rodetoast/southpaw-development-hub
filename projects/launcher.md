# Southpaw 도구 런처

사내 직원이 제작 도구를 설치·실행·업데이트하는 통합 런처입니다.

- **구현 범위** 도구 5개 관리, 서명 카탈로그 검증, GUI·Bootstrap 관리형 교체와 복구, Toast → Rod 전환, 설정과 테마
- **운영 버전** 0.2.2
- **개발 상태** 작업 공간 필터·정렬, 외부 도구 감지·창 전환, 관리형 바로가기와 QML 표면을 개발 브랜치에 반영했습니다. 운영은 0.2.2입니다.
- **다음 단계** 배포 후보 승인 후 패키징된 Windows 환경에서 기존 창 전환과 실제 도구별 업데이트 후 바로가기 동작을 확인합니다.
- **시각 검토 자료** 공식 회사 심볼은 헤더에 적용하고 기존 제품 아이콘은 제목 표시줄에 유지했습니다.
