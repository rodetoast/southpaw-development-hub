# TileNamer

타일 아티스트가 영역을 지정하고 명명 규칙에 맞춰 PNG로 내보냅니다.

- **구현 범위** 격자 기반 영역 지정, 배치 미리보기, 타일 이름 규칙과 가이드, PNG 출력
- **운영 버전** 0.1.6 RC3
- **개발 상태** RC3 운영. 배포 기록에서 실행에 필요한 내장 규칙 데이터를 포함합니다.
- **다음 단계** 후속 배포 시 규칙 데이터 및 Aseprite 연동 범위를 Windows에서 확인합니다.
- **확인일** 2026-11-24
